PHONE-FRIENDLY SETUP

Copy, paste, deploy

  1. 01
    Create a Cloudflare Worker

    On your phone, open Cloudflare → Workers & Pages. Create a Hello World Worker with the branded name above, then open Edit code.

  2. 02
    Paste the standalone code

    Tap Copy ready-to-deploy Worker here. It includes your panel URL and private token. Replace the entire example Worker with it, then deploy. No variables, PC or terminal are needed.

  3. 03
    Enable and share

    Paste the workers.dev URL here, leave Endpoint public IPv4 empty for automatic resolution, enable WEB proxy and save. Share the WEB link below.

Use your own Cloudflare account. The ready-to-deploy code contains a private token: do not publish it. Telegram clients must support WEB proxies.
